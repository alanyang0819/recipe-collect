# 料理誌

料理誌是一個以繁體中文呈現的料理食譜整理網站，將每一道料理整理成獨立的一篇，讓日常料理可以被清楚保存、快速找到，也方便慢慢累積成自己的味道資料庫。

## 網站特色

### 一道料理，一篇完整食譜

每道料理都有獨立的詳細頁，集中呈現料理名稱、分類、描述、份量、準備時間、烹調時間、材料、步驟與備註，閱讀時不需要在不同頁面之間來回尋找。

### 像料理雜誌一樣瀏覽

網站採用暖白與番茄紅的視覺風格，搭配醒目的標題、清楚的內容分區與料理卡片，讓食譜不只是資料，也具有適合閱讀的版面。

### 快速找到想做的料理

首頁提供料理卡片、關鍵字搜尋與分類篩選，可以依料理名稱、分類或既有關鍵字快速縮小範圍。

### 依分類探索不同味道

分類頁將料理依照中式、台式、日式、義式或其他既定分類整理，適合在還沒決定要做什麼時慢慢瀏覽。

### 圖片與文字並重

有提供料理圖片時，卡片與詳細頁會呈現圖片，幫助快速辨識料理；沒有圖片時則維持乾淨的文字版面，不顯示沒有意義的空白圖片框。

### 手機與桌面都容易閱讀

版面會依不同螢幕寬度調整，材料與步驟保持清楚易讀，搜尋、分類與導覽等互動功能也支援鍵盤操作。

### 只保存你提供的料理內容

網站內容以使用者提供的食材、份量、步驟與備註為準，只整理語句與格式，不自行添加未確認的料理資訊。

## 技術

本專案使用原生技術製作：

- HTML
- CSS
- JavaScript
- JSON

不使用前端框架、建置工具、外部套件、外部字體或伺服器端程式，可直接部署至 GitHub Pages。

## 專案結構

```text
.
├── index.html              # 所有料理與搜尋頁
├── categories.html         # 分類瀏覽頁
├── recipe.html             # 單篇料理詳細頁
├── css/
│   └── styles.css          # 網站樣式
├── js/
│   ├── app.js              # 料理列表、搜尋與分類篩選
│   ├── categories.js       # 分類頁功能
│   └── recipe-page.js      # 料理詳細頁功能
├── data/
│   ├── recipes.json        # 唯一料理索引
│   └── recipes/            # 各料理的獨立 JSON
└── images/                 # 料理圖片
```

## 新增料理

每道料理使用一份獨立 JSON，檔名使用英數 slug，例如：

```text
data/recipes/gong-bao-ji-ding.json
```

料理資料需包含固定欄位：

```json
{
  "slug": "gong-bao-ji-ding",
  "name": "宮保雞丁",
  "category": "中式料理",
  "tags": [],
  "image": "",
  "description": "",
  "servings": "",
  "prepTime": "",
  "cookTime": "",
  "ingredients": [],
  "steps": [],
  "notes": []
}
```

新增料理後，必須同步更新：

1. `data/recipes.json`
2. `data/recipes/<slug>.json`
3. 若有圖片，將圖片放入 `images/`，並在 `image` 欄位填入對應路徑

料理內容只整理使用者提供的資料，不自行補寫食材、份量、步驟、時間或其他事實。
